# دفتري — دفتر دين البقالة الذكي

مشروع Android أولي بلغة Kotlin وSQLite محلية، بواجهة عربية كبيرة، وإدارة زبائن، وتسجيل دين وتسديد، وحاسبة داخلية، وكشف حساب نصي، ومشاركة إشعارات عبر واتساب.

## تشغيل المشروع
1. فك ضغط ZIP.
2. افتح مجلد `DaftariSmart` باستخدام Android Studio حديث.
3. انتظر مزامنة Gradle ثم شغّله على هاتف Android أو محاكي.

## تسجيل الدخول بجوجل وحفظ البيانات بعد حذف التطبيق
هذه النسخة لا تتضمن تسجيل Google أو مزامنة سحابية مفعلة. يلزم إعداد مشروع Firebase خاص بك:
1. أنشئ مشروعاً في Firebase Console.
2. أضف تطبيق Android بالمعرّف `com.daftari.smart`.
3. فعّل Authentication > Google وأضف بصمات SHA-1/SHA-256 حسب إعداداتك.
4. نزّل `google-services.json` وضعه داخل مجلد `app/`، ثم أضف Google Sign-In/Firebase Auth إلى Gradle.
5. أضف Firebase Firestore أو خدمة سحابية أخرى، ثم برمج مزامنة الزبائن والحركات وقواعد الأمان. تسجيل الدخول وحده لا ينسخ البيانات احتياطياً.
6. اختبر استعادة البيانات على جهاز جديد قبل الاعتماد عليها.

## ملاحظات مهمة
- هذه نسخة بداية قابلة للتطوير وليست منتجاً تجارياً نهائياً؛ لم يتم اختبار البناء هنا داخل Android Studio.
- واتساب يفتح الرسالة للمراجعة والإرسال يدوياً، ولا يرسل تلقائياً بالخلفية.
- كشف الحساب نصي وليس PDF أو صورة حتى الآن.
- زر النسخة الاحتياطية يشارك محتوى نصياً؛ ينصح بإضافة تصدير واستيراد ملف JSON فعلي.
- تنبيه المتأخرين لأكثر من 15 يوماً، تقارير تفصيلية حسب طريقة القبض، نظام الاشتراك ورموز التفعيل، ومزامنة السحابة ما زالت تحتاج تطويراً.
- لا تضع مفاتيح أو بيانات اعتماد سرية داخل ZIP أو المستودع العام.
